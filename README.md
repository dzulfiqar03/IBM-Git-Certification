# Introduction to Git and GitHub

## Project Name
**Introduction-to-Git-and-GitHub**

## Description
This repository was created as part of the **IBM Developer Skills Network** course *"Introduction to Git and GitHub"*. It serves as a hands-on practice space for learning core version controls concepts and collaborative development workflows using Git and GitHub.

## Purpose
The main goals of this repository are to:
- Practice initializing and managing a Git repository
- Learn how to create, clone, and manage GitHub repositories
- Understand branching, merging, and pull requests
- Practice open-source repository hygiene (README, LICENSE, CODE_OF_CONDUCT, CONTRIBUTING files)
- Build familiarity with GitHub collaboration workflows

## Repository Structure
```
.
├── README.md

└── CONTRIBUTING.md
```

## Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/ibm-developer-skills-network/mcino-Introduction-to-Git-and-GitHub.git
   ```
2. Navigate into the project directory:
   ```bash
   cd mcino-Introduction-to-Git-and-GitHub
   ```
3. Explore the files and start practicing Git commands (add, commit, push, pull, branch, merge, etc.)
